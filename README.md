# 英雄体红色文字生成器

一个简单易用的在线工具，用于生成英雄体风格的文字图片，适用于社交媒体、海报和宣传材料。实际上是抖音上很火的权威字体。

在线体验：https://byebug.cn/hero-text-generator/

## 功能特点

- 使用汉仪英雄体字体，生成经典红色文字
- 可调整字体大小、字间距和行高
- 自定义文字颜色和背景颜色
- 支持透明背景导出，完美适配各种设计需求
- 文字阴影效果，增强视觉冲击力
- 自动调整字体大小，确保文本完美显示
- 导出正方形图片，适合社交媒体展示
- 多种导出方式，确保兼容各种浏览器

## 使用说明

1. 打开网页应用
2. 在文本框中输入需要生成的文字
3. 调整字体大小、字间距、行高等参数
4. 选择文字颜色和背景颜色
5. 可选择启用透明背景或文字阴影
6. 点击"生成预览"按钮查看效果
7. 满意后点击"导出图片"按钮下载生成的图片
8. 如果无法直接下载，可点击"显示图片"并右键保存

## 本地部署

1. 克隆此仓库到本地：
   ```
   git clone https://github.com/yourusername/hero-text-generator.git
   ```

2. 进入项目目录：
   ```
   cd hero-text-generator
   ```

3. 使用任意HTTP服务器运行项目，例如：
   ```
   python -m http.server
   ```
   或者使用VS Code的Live Server插件等

4. 在浏览器中访问 `http://localhost:8000`

## 技术实现

- 纯前端实现，无需后端服务
- 使用HTML5 Canvas技术生成图片
- 响应式设计，适配不同设备屏幕
